Project 2: Capstone Project (RevoU Cendikiawan)

Timeline: May 2024 - Jun 2024

This project develops an AI-powered chatbot to analyze and respond to Amazon product reviews using Amazon Q. The chatbot helps users explore product insights, receive recommendations, and improve their shopping experience by leveraging natural language processing and intelligent query handling.

Key Features

  • Review Analysis
  • Smart Recommendations
  • Interactive Chatbot
  • User Experience Enhancement
  • Scalable Integration

Technologies Used

Amazon Q, Python, NLP and AWS
